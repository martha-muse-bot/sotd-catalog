# SOTD canonical product catalog

Goal ID: goal_b33f8a336982
Goal slug: sotd-canonical-product-catalog

## Description
Building a canonical catalog of shaving products that messy SOTD entries can be matched to. Entries are keyed by blade format first, then brand and product name, each with an alias list and first-party evidence the user can validate; merge candidates, renames, and naming conventions are decided together. Blades come first, then razors, soaps, and the rest.
